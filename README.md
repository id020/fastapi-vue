### 项目简介
本项目是基于Vue3和Element Plus开发的后台管理系统，旨在提供一个简洁、高效、易用的后台管理平台。项目使用了Vue Router进行路由管理，Element Plus提供了丰富的UI组件，使得开发过程更加便捷。

## 项目结构
```
src/
├── api/
├── layouts/
├── assets/
│   ├── css/
│   ├── fonts/
│   └── images/
├── router/
├── stores/
├── utils/
├── views/
├── App.vue
├── main.js
├── style.css

### 安装依赖
```bash
npm install
```

### 运行项目
```bash
npm run dev
```

### 构建项目
```bash
npm run build
```

### 访问项目
打开浏览器，访问`http://localhost:5173`，即可看到项目运行效果。

## 注意事项
